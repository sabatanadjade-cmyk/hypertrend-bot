# 🤖 HyperTrend Bot - دليل التشغيل

## كيفاش البوت يشتغل

```
يراقب العملات كل 30 ثانية
         ↓
يحسب إشارات HyperTrend على 4 فريمات (1د، 3د، 5د، 15د)
         ↓
إذا تأكدت الإشارة على فريمين أو أكثر → يدخل بكل الرصيد
         ↓
يقسم الخروج:
  50% → TP1  (ثم SL ينتقل إلى نقطة الدخول)
  25% → TP2
  25% → TP3
```

---

## خطوات التشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إعداد مفاتيح Binance API
- افتح ملف `.env`
- ضع مفتاح الـ API الخاص بك:
```
BINANCE_API_KEY=مفتاحك_هنا
BINANCE_API_SECRET=المفتاح_السري_هنا
```

> ⚠️ **مهم:** عند إنشاء الـ API على Binance:
> - فعّل **Spot Trading** فقط
> - لا تفعّل السحب (Withdrawal)
> - قيّد الـ IP إذا أمكن

### 3. تعديل قائمة العملات (اختياري)
افتح `symbols.txt` وأضف أو احذف العملات كما تريد

### 4. تشغيل البوت
```bash
python bot.py
```

## شرح المنطق

| الشرط | القيمة |
|-------|--------|
| Supertrend | تقاطع صعودي |
| MACD | إيجابي ومتصاعد |
| EMA150 > EMA250 | اتجاه صاعد |
| ADX | أكبر من 20 (سوق متحرك) |
| تأكيد الفريمات | فريمين على الأقل |

## ملاحظات مهمة

- البوت **سبوت فقط** - لا فيوتشرز ولا ليفرج
- يدخل بـ **كل الرصيد المتاح** في USDT
- لا يفتح أكثر من صفقة واحدة لكل عملة في نفس الوقت
- اللوج يُحفظ في ملف `bot.log`
- الصفقات المفتوحة تُحفظ في `trades.json` (تبقى حتى لو أعدت تشغيل البوت)
